# FolioSwap project icon

`FolioSwap-Logo.svg` is the editable vector master. The open book, geometric rune marks and switching arrows were drawn for FolioSwap from SVG primitives. No Blizzard textures, stock icons, fonts or external images are embedded. This describes the asset's construction, not a legal guarantee of uniqueness.

Exports: `FolioSwap-Logo-512.png`, `FolioSwap-Logo-256.png`, `FolioSwap-Logo-64.png` and `FolioSwap-Logo-32.png`. Use the 512-pixel PNG for the Wago and CurseForge project image. The image has a dark rounded background with transparent outer corners.

Export with Python and resvg-py, using `resvg_py.svg_to_bytes(svg_string=svg_source, width=size, height=size)` for each output size.

These assets are for project-page branding only. They are not loaded by the addon or included in its release package. The repository LICENSE applies.
